## Brand Messaging

Primary tagline: **Built with the Right Tools. Finished the Right Way.**  
Craftsmanship statement: **Our Best Tool Is Precision. Our Standard Is Excellence.**

Use the wet saw/diamond-blade motif as supporting craftsmanship symbolism without making the site appear tile-only.

## Proof Architecture

`Our Work` should use only authorized real-project content. Each case study may include before/progress/after photos, project type, scope summary, craftsmanship notes, and customer testimonial/review only when authentic and permissioned.

AI-generated remodeling imagery must not be represented as completed work.

## Estimate Conversion

The estimate path should be short and mobile-first. Anticipated intake fields may include project type, location, desired timing, summary, photos, and contact information. Customer PII must never be committed to this public repository.

## Trust Architecture

Plan for:
- founder/craftsmanship story
- service-process clarity
- real reviews when earned
- licensing/insurance statements only when verified
- clear service area
- clear communication expectations
- truthful portfolio
- privacy/accessibility baseline

## Local SEO / Structured Data

Build Room 01 should plan technically valid metadata, page titles/descriptions, local-business structured data only after legal/business facts are verified, service-area content, semantic headings, performant images, sitemap/robots strategy, and canonical URLs.

Do not fabricate address, license, years-in-business, review totals, service coverage, or credentials for SEO.

## Analytics / Attribution

Plan event measurement for:
- estimate-form starts/submissions
- click-to-call
- email/contact clicks
- service-page engagement
- portfolio interactions
- lead-source attribution

Analytics implementation must respect privacy requirements and be explicitly selected later.

## Accessibility

Mobile-first responsive implementation, keyboard-accessible navigation/forms, labeled controls, visible focus, sufficient contrast, alt text, reduced-motion support, and semantic HTML should be baseline requirements.

## Deployment Boundary

No website is built or deployed by this record. Domain, hosting, analytics, forms/backend, business contact data, and final visual identity require later authorization/evidence.

## A. Kill Switch

**PASS.** `generate-concept` computes:

- `BR02_OPENAI_ENABLED` as enabled only when its value is exactly `true`;
- `BR02_KILL_SWITCH` as closed unless its value is exactly `false`.

Therefore an absent `BR02_OPENAI_ENABLED`, `BR02_OPENAI_ENABLED=false`, an
absent `BR02_KILL_SWITCH`, or `BR02_KILL_SWITCH=true` returns HTTP 503
`GENERATION_DISABLED` before source download or the OpenAI request function.
OpenAI can be reached only when both `BR02_OPENAI_ENABLED=true` and
`BR02_KILL_SWITCH=false` are deliberately configured.

## B. Missing OpenAI Secret

**PASS.** With the two switches deliberately open but `OPENAI_API_KEY` absent,
`generate-concept` returns HTTP 503 `GENERATION_DISABLED` before any provider
request. The key is read only in the server-side Edge Function and is never
returned in a response.

## C. Project Concept Cap

**PASS.** The adopted limit is four concepts per project.
The new `br02_reserve_generation` database function checks the project count and
the requested ordinal under a project advisory transaction lock, then creates
the `generating` concept and its attempt reservation in the same transaction.
The function is revoked from `public`, `anon`, and `authenticated` and granted
only to `service_role`; browser JavaScript cannot bypass it.

## D. User Rate Limit

**PASS.** The adopted server-side limit is eight attempt
events for an authenticated user in the preceding rolling 24 hours. The atomic
reservation locks by user ID before counting and inserting the new attempt.

## E. IP Rate Limit

**PASS.** The adopted server-side limit is three attempt
events for one hashed IP in the preceding rolling hour. `hmacIpHash` derives an
HMAC-SHA-256 value from the forwarded edge IP using `BR02_IP_HASH_SALT`; only
that derived value is stored in `generation_events`, never the raw IP.

The earlier source path could omit this quota when the salt or an edge IP header
was unavailable. It now fails closed with HTTP 503 `GENERATION_DISABLED` before
reservation, source download, or provider contact whenever an IP hash cannot be
derived.

## F. Spend Control

**PASS.** The application defaults remain a $20 monthly
ceiling and a $0.08 reserved cost for each attempted generation, sourced from
`BR02_MONTHLY_BUDGET_USD` and `BR02_RESERVED_COST_PER_CALL_USD` with those
fail-safe defaults. The reservation function serializes monthly checks with an
advisory transaction lock and writes the attempt reservation atomically, so
concurrent requests cannot pass the same available-budget calculation.

The previous read-then-insert implementation could overspend under concurrency.
The hosted migration is applied and behaviorally verified. Application controls
remain defense in depth and do not replace OpenAI Platform billing controls.

## H. Timeout and Retry

**PASS.** `callOpenAI` establishes one 120-second total deadline shared by all
attempts. It permits an initial request plus at most two retries, with bounded
exponential backoff plus jitter, only for HTTP 429 and 5xx provider responses.
The retry delay must still fit within the original deadline. Abort errors return
`GENERATION_TIMEOUT`; non-retryable 4xx responses and network errors normalize
to `GENERATION_FAILED` without exposing provider details.

## I. Moderation and Error Handling

**PASS.** Provider `moderation_blocked` normalizes to `MODERATION_BLOCKED` and
sets the concept state to `blocked`. Invalid or non-ready source assets return
`UPLOAD_NOT_READY`; unsupported/non-retryable provider responses, malformed
success payloads, and provider failures normalize to `GENERATION_FAILED`; 429
and 5xx are bounded as described above; deadline expiry normalizes to
`GENERATION_TIMEOUT`. The JSON response allowlist contains only normalized error
codes, never an OpenAI key, Supabase secret, stack trace, or raw provider body.

## J. Model and Request Policy

**PASS.** The static request policy is `gpt-image-2` Image Edits, one image
(`n=1`) per call, `medium` quality, `1536x1024`, and WEBP output. The result is
stored in the private results bucket with a SHA-256 digest and provenance record.

## K. Prompt Governance

**PASS.** The server-side compiler preserves source-space truth, preserve/change/
must-have items, design direction, accessibility goals, and source-photo
geometry rules. Its explicit conceptual-visualization disclosure prohibits
construction or engineering drawings, permit/code approval, final dimensions,
guaranteed materials, and construction quotes. Only the compiler version and
prompt hash are persisted; raw compiled prompt text is not stored by default.

## Source Hardening Applied

The T07 audit found two material pre-generation flaws and corrected them without
opening the OpenAI gate:

1. Quota and budget checks were separate read-then-write operations and could be
   bypassed by concurrent requests. Migration
   `20260813000300_br02_atomic_generation_reservation.sql` creates the locked,
   service-only atomic reservation function; `generate-concept` now uses it.
2. A missing IP-hash salt or edge IP header could omit the IP rate limit.
   `generate-concept` now returns `GENERATION_DISABLED` when it cannot derive an
   IP HMAC.

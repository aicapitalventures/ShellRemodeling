## Research Verdict

Basic AI remodel visualization is **NOT UNIQUE** in the 2026 market. Multiple services already allow customers or contractors to upload photos and generate remodel concepts, and several add proposals, cost ranges, materials, CRM, or lead capture.

Shell & Co’s proposed product differentiation is therefore the integrated contractor workflow:

**Space Truth Intake → Preserve / Change / Must-Have → Multi-Concept AI Visualization → Customer Selection → Human Buildability Review → Precision Scope Map → Pre-Estimate Intelligence Packet → Site Visit / Estimate**

This differentiation is a product/workflow strategy. It is not a patentability or exclusivity determination.

## OpenAI Integration Boundary

The frontend is GitHub Pages compatible, but live OpenAI requests must not originate from browser code containing a secret key.

Required production pattern:

`GitHub Pages frontend → secure backend/serverless API → OpenAI API → approved private storage/result handling → frontend + Shell & Co operations`

Backend provider, customer-photo storage, retention/deletion policy, authentication/rate limiting, spend limits, privacy terms, and production API model settings remain unresolved.
